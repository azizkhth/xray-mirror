Ready-to-load folders (each has parts.txt: file id and English name)
  1-skull-bones      23 bones of the skull (the mandible opens with your mouth)
  2-eyes             eyeballs, corneas, irises, lenses, lacrimal glands
  3-cervical-spine   C1-C7 and the discs between them
  4-brain            59 parts: gyri, lobes, cerebellum, brainstem, ventricles

How to use
  1. Open xray-mirror.html in Chrome and press the start button.
  2. In the panel, press "تحميل نموذج" and select ALL files in one folder
     (Ctrl+A in the file dialog). You can load several folders one after another;
     they line up because BodyParts3D parts share one coordinate system.
  3. Tick "إخفاء الأشكال المبسّطة" to see only the real models.
  4. Use the size / up-down / forward-back sliders if the model needs fine-tuning.

download/ holds the original archive and the official name lists.
